# .github

Default community health files for the [cdxgen](https://github.com/cdxgen) organization. GitHub uses these files for any repository in the organization that does not have its own copy.

- [CONTRIBUTING.md](CONTRIBUTING.md): how to contribute, including how we handle AI-assisted contributions
- [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md): the default pull request description
- [SECURITY.md](SECURITY.md): how to report a vulnerability
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md): the code of conduct for all cdxgen spaces
- [profile/README.md](profile/README.md): the introduction shown on the organization's GitHub page
